This is meant for Stardance a teen STEM program that gives prizes in exchange for projects. Our protagonist is doing a feat of immense danger and skill, gliding down a mountain while there's a storm. In order to do this he must traverse the caves going down. Land with the glider to complete the levels. Will you be able to survive? Find out now. Controls are just a click away in the menu accessible by clicking escape.

## How to Access:

To access the game go to https://netheritedog.itch.io/storm-glide, or use the build in packages. If using build in packages make sure to unzip the file and then play the EXE.

## Information about game state:

There may be bugs in game that were not properly taken care of or left in. Any and all bugs are 100% purposefully put there to emulate the feeling of a really bad PS1 game and there is no reason to question them. It is not extremely polished but it works.

## History:

This game started off 2 months ago when I discovered Stardance and after a bit of tinkering with what game mechanics I wanted I settled on managing how to use your glider along side some grappling. Previous ideas involved having momentum or gliding with some cool physics but were scrapped for being too hard. The only hiccup I encountered was dealing with school so there are only 7 levels. However I may update this game with more. Please appreciate the renders I worked very hard on them.

## Controls:

Controls are in the pause menu however if you hate pausing here are the controls here
Escape: Pause
Space: Jump/Wall Jump
WASD: Movement
Left Click: Grapple

## Features:

Along side basic controls there is grappling, gliding, wall running, wall sliding, and wall jumping. There are 7 levels, visual effects, title screen and sound effects.
